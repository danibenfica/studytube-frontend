# 🔌 4.4 Contrato consumido e mapa de dados

> **FONTE ÚNICA** O contrato oficial é o da API ([backend 4.4](https://github.com/danibenfica/studytube-backend/blob/main/docs/04.4-contrato-da-api.md) e `/openapi/v1.json`). Aqui está **como a tela usa** esse contrato.

**Endereço base:** `import.meta.env.VITE_API_URL ?? "http://localhost:5126/api/videos"` (arquivo `src/api/videosApi.ts`).

## 4.4.1 Funções de integração

| Função (`videosApi.ts`) | Chamada HTTP | Usada em | Caso de uso |
|---|---|---|---|
| `getVideos()` | `GET {API_URL}` | `useVideos` (carga da página) | UC_002 |
| `addVideo(url)` | `POST {API_URL}` com `{ "url": "..." }` e `Content-Type: application/json` | `useVideos.add` | UC_001 |
| `markAsWatched(id)` | `PATCH {API_URL}/{id}/watched` | `useVideos.toggleWatched` (quando `watched = false`) | UC_003 |
| `markAsUnwatched(id)` | `DELETE {API_URL}/{id}/watched` | `useVideos.toggleWatched` (quando `watched = true`) | UC_004 |

**Tratamento de resposta (`handleResponse`).** Se `res.ok` for falso, tenta ler o JSON e lança `Error(body.error)`; se não houver `error` (ou o corpo não for JSON), lança `Error("Algo deu errado 😢")`. Falha de rede (API desligada) rejeita o `fetch` com o erro do navegador.

## 4.4.2 Mapa de dados — `VideoDto` (API) → `Video` (TypeScript) → tela

| Campo JSON | Tipo em `types/Video.ts` | Onde aparece na tela |
|---|---|---|
| `id` | `string` | Chave do card; rota de marcar/desmarcar. |
| `youTubeId` | `string` | Enviado ao player (`videoId`). |
| `title` | `string` | Título do card e texto alternativo da miniatura. |
| `channelTitle` | `string` | "canal • duração". |
| `thumbnailUrl` | `string` | Miniatura do card. |
| `duration` | `string` (`TimeSpan` do .NET, ex.: `"00:04:13"`) | Formatada por `formatDuration` (RNW08). Também aceita ISO 8601 (`PT4M13S`). |
| `watched` | `boolean` | Classe `card watched`, texto do botão e contador. |
| `addedAt` | `string` | Não exibido (a ordem vem da API). |
| `watchedAt` | `string \| null` | Não exibido. |
