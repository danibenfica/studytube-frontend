# ⚙️ 4.6 Procedimento operacional

> **AMBIENTE** Somente desenvolvimento local. Não há hospedagem publicada.

## 4.6.1 Pré-requisitos

- Node.js 24 (arquivo `.nvmrc`) — o `package.json` aceita `^22.13.0 || ^24.0.0 || >=26.0.0`.
- StudyTube API rodando em `http://localhost:5126` para usar com dados reais.

## 4.6.2 Instalar e configurar

```powershell
npm ci
copy .env.example .env
```

O `.env` contém só `VITE_API_URL=http://localhost:5126/api/videos` (não é segredo, mas não é versionado). Sem `.env`, o código usa esse mesmo endereço como padrão.

## 4.6.3 Comandos

| Objetivo | Comando |
|---|---|
| Rodar em desenvolvimento | `npm run dev` (Vite; endereço exibido no terminal, por padrão `http://localhost:5173`) |
| Testes | `npm test` (`vitest run`) |
| Lint | `npm run lint` |
| Build de produção | `npm run build` (gera `dist/`) |
| Pré-visualizar o build | `npm run preview` |

## 4.6.4 Hooks e CI

- `npm ci` executa `prepare` → `husky`, que instala o hook `pre-commit` (`npm run lint` + `npm test`). Commit com lint ou teste quebrado é bloqueado.
- O workflow `CI` roda em push na `main` e em todo pull request, em Ubuntu e Windows.

## 4.6.5 Diagnóstico rápido

| Sintoma | Causa provável | Ação segura |
|---|---|---|
| "Não consegui falar com a API. Ela está rodando? 🥺" | API parada ou em outra porta. | Subir a API com `--launch-profile http`; conferir `VITE_API_URL`; recarregar a página. |
| "Algo deu errado 😢" ao adicionar | A API falhou ao consultar o YouTube (chave/cota) ou erro inesperado. | Ver o console da API (documentação do backend, 4.6.6). |
| `npm ci` reclama da versão do Node | Node abaixo de 22.13. | Instalar o Node 24 (`.nvmrc`). |
