# 📝 4.3 Histórias de usuário e critérios de aceitação

> **COMO LER** Cada história resume o valor para o estudante ("Como <papel>, quero <ação>, para <benefício>") e aponta para o caso de uso que a detalha. Os critérios de aceitação estão escritos do ponto de vista **da tela** e indicam o fluxo (FP, FA, FE) correspondente. Os mesmos códigos `US_xxx` existem no backend, com critérios do ponto de vista da API.

## US_001 – Adicionar videoaula pelo link (UC_001, UC_007)

**Como** estudante, **quero** colar o link de um vídeo do YouTube e adicioná-lo, **para** montar minha lista sem digitar título, canal e duração.

| # | Critério de aceitação (Dado / Quando / Então) | Fluxo |
|---|---|---|
| CA1 | **Dado** o campo vazio, **então** a opção "Adicionar ✨" fica indisponível. | FE_01 |
| CA2 | **Dado** um link válido de vídeo, **quando** peço para adicionar, **então** a videoaula aparece no topo da lista com miniatura, título, canal e duração, o campo fica vazio e o progresso é atualizado. | FP |
| CA3 | **Dado** um link `https://youtu.be/{id}`, **quando** peço para adicionar, **então** funciona igual ao link completo. | FA_01 |
| CA4 | **Dado** um link de outro site, **quando** peço para adicionar, **então** vejo o aviso "Esse link não é do YouTube 🥺", a API não é chamada e o link continua no campo. | FE_02 |
| CA5 | **Dado** um vídeo que já está na lista, **quando** peço para adicionar, **então** vejo "Este vídeo já está na sua lista." e o link continua no campo. | FE_03 |
| CA6 | **Dado** que a API falhou sem mensagem, **então** vejo "Algo deu errado 😢". | FE_04 |

## US_002 – Ver minha lista de videoaulas (UC_002)

**Como** estudante, **quero** ver minhas videoaulas assim que abro a página, das mais recentes para as mais antigas, **para** saber o que tenho para estudar.

| # | Critério de aceitação | Fluxo |
|---|---|---|
| CA1 | **Dado** que tenho videoaulas, **quando** abro a página, **então** vejo um card por videoaula com miniatura, título e "canal • duração" (ex.: `Canal • 4:13`). | FP |
| CA2 | **Dado** que não tenho videoaulas, **então** vejo "Nenhum vídeo ainda... cole seu link aqui! 🐰". | FE_01 |
| CA3 | **Dado** que a API está desligada, **quando** abro a página, **então** vejo "Não consegui falar com a API. Ela está rodando? 🥺". | FE_02 |

## US_003 – Marcar videoaula como assistida (UC_003)

**Como** estudante, **quero** marcar "Já assisti" numa videoaula, **para** saber o que já estudei.

| # | Critério de aceitação | Fluxo |
|---|---|---|
| CA1 | **Dado** uma videoaula não assistida, **quando** escolho "✔ Já assisti", **então** o card fica destacado, a opção vira "↩ Desmarcar" e o contador aumenta. | FP |
| CA2 | **Dado** que a API recusa, **então** vejo a mensagem e o card não muda. | FE_01, FE_02 |

## US_004 – Desmarcar videoaula (UC_004)

**Como** estudante, **quero** desmarcar uma videoaula, **para** corrigir um engano ou rever o conteúdo.

| # | Critério de aceitação | Fluxo |
|---|---|---|
| CA1 | **Dado** uma videoaula assistida, **quando** escolho "↩ Desmarcar", **então** o card volta ao normal, a opção vira "✔ Já assisti" e o contador diminui. | FP |
| CA2 | **Dado** que a API falha, **então** vejo a mensagem e o card não muda. | FE_01, FE_02 |

## US_005 – Assistir sem sair da página (UC_005)

**Como** estudante, **quero** assistir à videoaula dentro do StudyTube, **para** estudar sem me perder em outras abas do YouTube.

| # | Critério de aceitação | Fluxo |
|---|---|---|
| CA1 | **Dado** uma videoaula na lista, **quando** escolho "▶ Assistir" ou a miniatura, **então** o player aparece acima da lista e o vídeo começa a tocar. | FP |
| CA2 | **Dado** o player aberto, **quando** escolho "Fechar player ✖", **então** o player some. | FP |
| CA3 | **Dado** o player aberto, **quando** escolho outra videoaula, **então** o player troca de vídeo. | FA_01 |
| CA4 | Assistir **não** marca a videoaula como assistida. | RNW09 |

## US_006 – Acompanhar meu progresso (UC_006)

**Como** estudante, **quero** ver quantas videoaulas já assisti do total, **para** me motivar e planejar os estudos.

| # | Critério de aceitação | Fluxo |
|---|---|---|
| CA1 | **Dado** 3 videoaulas com 1 assistida, **então** vejo "1 de 3 assistidos 🌸". | FP |
| CA2 | **Dado** a lista vazia, **então** o indicador não aparece. | FE_01 |
